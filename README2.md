Проект Charity Management System представляет собой систему управления данными благотворительной организации. В рамках первого этапа разработки реализована интеграция объектно-ориентированной логики приложения с реляционной базой данных PostgreSQL. Программный комплекс позволяет автоматизировать учет доноров и мониторинг пожертвований.

Технологический стек включает язык программирования Java 25 и систему управления базами данных PostgreSQL. Для взаимодействия с БД используется технология JDBC с драйвером версии 42.7.3.

В программной части реализованы сущности Donor, Charity и Donation. Использованы принципы инкапсуляции, а также механизмы сортировки и фильтрации данных через стандартные коллекции Java. Логика работы с данными вынесена в специализированные DAO классы.

Функционал работы с базой данных обеспечивает автоматическое создание необходимых таблиц при запуске приложения. Реализованы базовые CRUD операции: добавление новых доноров в базу, чтение актуальных списков, обновление контактных данных существующих пользователей и удаление записей. Все запросы к базе данных выполняются с использованием PreparedStatement для обеспечения безопасности и корректности данных.
